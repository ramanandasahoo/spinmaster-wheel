# 🎡 SpinMaster – Random Spin Wheel

A customizable spin wheel for making random decisions!

## 🚀 Live Demo

👉 **[Open SpinMaster](https://ramanandasahoo.github.io/spinmaster-wheel/)**

Try it directly in your browser—no installation required!

## ✨ Features

- 🎡 Random spin wheel
- 🔊 Sound effects
- 🎨 Customizable colors and themes
- 💾 Save and load wheels
- ↩️ Undo and redo
- 📜 Spin history
- 📱 Installable on Android
- 🌐 Offline support

## 📱 Installation

Open the live demo in Chrome on Android and use the browser menu to install SpinMaster.
